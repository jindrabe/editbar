# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), v2.1.

In short: be respectful, assume good faith, and keep discussion focused on
the project. Harassment, personal attacks, and off-topic disruption are not
welcome.

Report unacceptable behavior by opening a confidential issue or contacting
the maintainers directly. Reports will be handled with discretion.
